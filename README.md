# DogLongevityGuide.com

The science of longer, healthier lives for dogs — explained in plain English for dog parents in the US, UK, Canada and beyond.

A static, single-page blog: Longevity 101, the LOY-001 / LOY-002 / LOY-003 FDA tracker, full-length longevity guides, an interactive breed longevity database (23 breeds), a printable Senior Dog Longevity Checklist, and a Product Lab with honest evidence verdicts.

## Live deploy (free, via Netlify)
1. Push this repo to GitHub (public repo, e.g. `doglongevityguide`).
2. Go to netlify.com → **Add new site → Import an existing project → GitHub** → pick this repo.
3. Build settings: **Build command: (leave empty)**, **Publish directory: `.`** — `netlify.toml` in this repo already sets this.
4. Deploy. Netlify gives a free live URL like `doglongevityguide.netlify.app`.

No build step, no server, no cost. To update the site, edit `index.html` and push — Netlify redeploys automatically.
